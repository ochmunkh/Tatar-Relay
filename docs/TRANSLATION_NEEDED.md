# Translation needed — Mongolian

A worklist, not a translation. **Nothing here has been machine-translated**, and
nothing should be: the Mongolian in this repo is written, and a transliterated
stand-in would be worse than an honest gap.

Generated 2026-09-30 by classifying every tracked `.md` as entirely English,
bilingual (has a `Монгол` half), or mixed. Word counts are of the English body,
excluding fenced code blocks' surrounding prose only where noted — treat them as
sizing, not billing.

**Priority is about who reads the file**, not how long it is:

- **High** — an operator reads it *while doing the work*. A pentester mid
  engagement should not have to read English to get the tool working.
- **Low** — only someone changing the code reads it. English is defensible here;
  the whole Go/Python/Java vocabulary it sits in is English anyway.

## Deliberately *not* a gap

Listing these so nobody spends an evening on them:

- **`README.md`, `docs/POSITIONING.md`, `docs/target-classes.md`** already carry
  a Mongolian half. `tools/readme_parity.py` gates the README's two halves
  structurally in CI; if a half drifts, that check fails and names the mismatch.
  Those are maintenance, not translation.
- **`docs/QUICKSTART-MN.md`** is the Mongolian quick start and is already the
  Mongolian-first document.
- **`CHANGELOG.md`, `docs/algorithms.md`, `docs/user-guide.md`,
  `docs/architecture.md`, `docs/how-to-add-algorithm.md`** are already mixed
  Mongolian/English throughout rather than English-only.
- **`.pytest_cache/README.md`** is generated by pytest and is not tracked.

## If you translate one thing

`examples/js-hooks/BURP_INJECT_GUIDE.md`. It is short, it is procedural, and it
is the document an operator has open at the moment the tool either works or
does not.
